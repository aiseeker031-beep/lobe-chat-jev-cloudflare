# Lobe Jev Lite\n\nStripped Cloudflare-native fork of AIDotNet/lobe-chat.\n\nIncluded: Lobe-style chat UI, one custom OpenAI-compatible provider configured in the frontend, custom HTTP/Streamable HTTP MCP servers, and Cloudflare `typesafe/jev` as the routing/tool-selection brain.\n\nRemoved: built-in provider zoo, image/video generation, TTS/STT, marketplace, database/auth/vector stacks, Vercel/Docker runtime code, and large release/test/telemetry dependencies.\n\nFlow: user message → MCP discovery → Jev direct/tool decision → selected MCP call → custom model final answer. Jev is the decision brain, not the text generator.\n\nDeploy with `npm install && npx wrangler deploy`. The Workers AI binding is already declared as `AI`.\n\nRemote HTTP MCP is supported; stdio MCP is intentionally unsupported on Workers. Provider/MCP credentials are kept in browser localStorage and sent to this Worker only when needed.\n\nThe upstream LICENSE is retained; review its additional commercial-use conditions before commercial distribution.
